# Meteor Dodge

**Play a fast‑paced arcade game directly in your browser.**

## How to run
1. Clone or download the repository.
2. Open `index.html` in any modern browser (desktop or mobile).
3. No server or installation is required – the game runs completely client‑side.

## Controls
- **Desktop:** Arrow keys **←** / **→** or **A** / **D** to move the ship left and right.
- **Mobile / Touch devices:** Touch anywhere on the screen to move the ship horizontally.

## Objective
Avoid the falling meteors for as long as possible. Your score increases with the time survived. When a meteor hits the ship, the game ends. Press **Restart** to play again.

## Files
- `index.html` – page layout and canvas element.
- `style.css` – responsive styling.
- `game.js` – all game logic.
- `assets/ship.svg` – simple ship graphic.
- `assets/meteor.svg` – meteor graphic.

Enjoy the game and try to beat your high score!
